# DataLens — CSV Analytics Dashboard

DataLens is a beginner-friendly Data Science web
application built using Python.

## Features

- CSV file upload
- Dataset preview
- Statistical analysis
- Missing value detection
- Data visualization
- Correlation analysis
- Dataset download

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## Live Demo

Paste your deployed Streamlit URL here.

## How It Works

Users upload a CSV dataset. DataLens analyzes the
dataset and displays statistics and visualizations
through an interactive dashboard.
